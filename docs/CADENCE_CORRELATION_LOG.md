# Cadence Correlation Campaign Log

This document is the execution record for validating the ideal-tail 5T-OTA
sizing pipeline against Cadence Spectre. It records inputs, assumptions,
commands, failures, fixes, and measured results. Canonical machine-readable
records will live under `evaluation_results/cadence_correlation/`.

## Campaign contract

- Circuit: the fixed differential-pair/current-mirror OTA in
  `5T_OTA_netlist_cadence.txt`.
- Tail: ideal current sink from the common-source node to ground.
- Technology: TSMC 65 nm PDK used by the supplied Cadence netlist.
- Nominal supply: 1.2 V.
- Nominal input common mode: 0.6 V.
- Matched geometry: M9=M8 and M1=M0.
- Sizing source: verified surrogate pipeline, with local/global fallback
  recorded separately.
- Simulator is the final authority for correlation. LUT verification and
  Spectre verification must never be conflated.

### Frozen measurement definitions

The differential open-loop transfer function is

\[
A(s)=\frac{V_{out}}{V_{in+}-V_{in-}}.
\]

- Gain: low-frequency `20*log10(|A|)` in dB.
- GBW: first falling 0 dB crossing.
- Phase margin: `180 deg + phase(A)` at the GBW crossing, with the transfer
  polarity selected so low-frequency phase is near 0 degrees.
- Power: `VDD*abs(I(VDD source))` at the DC operating point.
- Every job also records Vout, tail/mirror voltages, branch currents, gm,
  gds, gmbs, and available intrinsic capacitances.

### Initial acceptance tolerances

| Quantity | Correlation tolerance |
|---|---:|
| DC gain | <= 1 dB absolute error |
| GBW | <= 10% relative error |
| Phase margin | <= 5 degrees absolute error |
| Power | <= 5% relative error |
| DC node voltage | <= 30 mV absolute error |
| gm and gds | <= 10% relative error |
| False proxy passes | 0 |

## 2026-09-03 — Step 4: host campaign automation

Implemented the host-side automation for a blind 25-case nominal-corner
correlation campaign.

Campaign composition is deterministic and disjoint:

| Regime | Cases | Selection intent |
|---|---:|---|
| Low power | 5 | Stress the low-current end of the feasible test domain |
| High gain | 5 | Stress the largest requested DC gains |
| High GBW | 5 | Stress the largest requested unity-gain frequencies |
| Heavy load | 5 | Prioritize large CL, then GBW |
| Near boundary | 5 | Requests closest to a stored feasibility boundary |

Only held-out `test` requests with a positive stored verifier verdict are
eligible. A source request cannot appear in two categories.

Implemented files:

- `analog_ai/correlation/campaign.py`: selection, frozen tolerance rules,
  private prediction/Spectre joins, measured constraint checks, and summary
  generation.
- `scripts/build_cadence_campaign.py`: runs the complete sizing ladder using
  the frozen champion and solved typical-corner LUT oracle, re-evaluates the
  selected design, converts gm/Id design variables to physical W/L/current,
  and creates 25 reproducible jobs.
- `scripts/stage_cadence_campaign.py`: copies only `input.scs`, `measure.ocn`,
  `design.json`, and `job.json` to the shared folder. Request specifications
  and LUT-predicted results remain on the host as private evidence.
- `scripts/collect_cadence_campaign.py`: collects atomic Spectre JSON,
  evaluates the frozen correlation tolerances and the original requested
  constraints, and writes JSON plus Markdown evidence.
- `tests/test_correlation_campaign.py`: selection, tolerance, blind staging,
  and result-join tests.
